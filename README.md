# Atomic Periodic Table — Android

A chemistry reference app for Android featuring an on-device AI agent, periodic table browser, unit tools, and more.

| AI Agent (architecture, language support, data models) | [docs/AI_AGENT.md](docs/AI_AGENT.md) |

## Quick start

```bash
# Clone and open in Android Studio
git clone https://github.com/JLindemann42/Atomic-Periodic-Table.Android.git
```

Requires Android Studio Hedgehog or later, AGP 9+, and a Firebase project with
`google-services.json` placed in `app/`.
